# Cymodocea rotundata

Reference species. These files are the current ones. Older tries are in `earlier/`.

| Role | File |
|------|------|
| Blender for the phone model | `cymodocea_rotundata.blend` |
| Blender for the lesson | `cymodocea_rotundata_lesson.blend` |
| Lesson video | `cymodocea_rotundata_lesson.mp4` |
| Phone model | `cymodocea_rotundata.glb` |

The app plays the copies in `app/assets/models-3d/`. The phone `.glb` and the lesson are the same meadow: 19,970 triangles, one `Grow` clip, no camera. The lesson is 30.000 seconds, 1920×1080, with English speech and the same words in subtitles along the bottom. There is no music. Both lesson copies are 5,940,175 bytes.

Build scripts live in `assets/models-3d/rotundata_build/`. The brief is `PLAN.md` in this folder.
