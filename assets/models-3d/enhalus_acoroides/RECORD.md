# Enhalus acoroides

These four files are the current ones.

| Role | File |
|------|------|
| Blender for the phone model | `enhalus_acoroides.blend` |
| Blender for the lesson | `enhalus_acoroides_lesson.blend` |
| Lesson video | `enhalus_acoroides_lesson.mp4` |
| Phone model | `enhalus_acoroides.glb` |

The app plays the copies in `app/assets/models-3d/`:

- `enhalus_acoroides.glb` — the plant you rotate. Four shoots, 21,908 triangles, clip `Grow` (frames 1–330 at 30 fps, frame 330 matches frame 1). No camera.
- `enhalus_acoroides_lesson.mp4` — the lesson, 30.000 seconds, 1920×1080. Spoken English with the same words in subtitles along the bottom. No music. The app copy is the same file.

The meadow is long inrolled ribbons, a thick rhizome with long black bristles, and cord-like roots in a solid uneven sand bed with a front cut. Build scripts live in `assets/models-3d/enhalus_acoroides_build/`. The brief is `PLAN.md` in this folder.
