# Halodule pinifolia

These four files are the current ones.

| Role | File |
|------|------|
| Blender for the phone model | `halodule_pinifolia.blend` |
| Blender for the lesson | `halodule_pinifolia_lesson.blend` |
| Lesson video | `halodule_pinifolia_lesson.mp4` |
| Phone model | `halodule_pinifolia.glb` |

The phone model is 20,990 triangles. It has one clip, `Grow`, and no camera. The same file is in `app/assets/models-3d/halodule_pinifolia.glb`.

The lesson is 30 seconds, 1920×1080. Subtitles sit along the bottom and use the same words as the speech. There is no music. The same film is in `app/assets/models-3d/halodule_pinifolia_lesson.mp4`.

The meadow is a fine pale patch on one solid sand bed. The bed is uneven, with a front cut. Each leaf is narrow, with one dark vein that divides at a rounded tip. The rhizome is pale, with clean black leaf scars, and fine roots grow down at the nodes.

Build scripts live in `assets/models-3d/halodule_pinifolia_build/`. The brief is `PLAN.md` in this folder.
