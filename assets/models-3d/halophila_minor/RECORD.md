# Halophila minor

These four files are the current ones.

| Role | File |
|------|------|
| Blender for the phone model | `halophila_minor.blend` |
| Blender for the lesson | `halophila_minor_lesson.blend` |
| Lesson video | `halophila_minor_lesson.mp4` |
| Phone model | `halophila_minor.glb` |

The app plays the copies in `app/assets/models-3d/`:

- `halophila_minor.glb` — the plant you rotate. Eight shoots, 10,626 triangles, clip `Grow` (frames 1–330 at 30 fps, frame 330 matches frame 1). No camera.
- `halophila_minor_lesson.mp4` — the lesson, 30 seconds at 1920×1080, with the five spoken lines

No growth clip. No pitch audio. No blend under `app/`.

Build scripts live in `assets/models-3d/halophila_minor_build/`. The brief is `halophila_minor.md` in this folder.
