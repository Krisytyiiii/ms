# Halophila ovalis

These four files are the current ones.

| Role | File |
|------|------|
| Blender for the phone model | `halophila_ovalis.blend` |
| Blender for the lesson | `halophila_ovalis_lesson.blend` |
| Lesson video | `halophila_ovalis_lesson.mp4` |
| Phone model | `halophila_ovalis.glb` |

The app plays the copies in `app/assets/models-3d/`:

- `halophila_ovalis.glb` — the plant you rotate. 14,810 triangles. One `Grow` action. No camera.
- `halophila_ovalis_lesson.mp4` — the lesson. 30 seconds, 1920×1080, 30 fps. Microsoft David Desktop speaks the script. The same words sit in subtitles along the bottom. No music.

The phone model and the lesson show the same meadow: paired oval leaves, eight cross veins, no hairs, a thin rhizome, and fine roots at the nodes. The sand is one solid warm pale bed with mounds, a dip, small ridges, and a front cut. The lesson opens on that bare bed, then the first pairs, then a close view where the cross veins can be counted.

No growth clip. No pitch audio. No blend under `app/`. No evaluation row was marked met.

Build scripts live in `assets/models-3d/halophila_ovalis_build/`. Entry scripts live in this folder. The note is `halophila_ovalis.md`.
