# Halophila ovalis

Spoon seagrass for the phone viewer. A display, not a scan of a Mati meadow.

Paired oval leaves rise from the rhizome on short petioles. There is no erect strap and no hairs on the leaf. `cross_vein_pairs` is 8, the bottom of the "eight or more" range. Fewer than 8 is *Halophila minor*. Blade size is a display choice, larger than a small oval, and it is not a spoken millimetre.

The phone file and the lesson use the same patch and the same sand bed. The bed is solid and uneven, with a front cut so the rhizome and the fine roots can be seen. The lesson opens on that bare bed, then raises the first pairs, then holds close on one oval so the eight cross veins can be counted.

The phone file is action `Grow`, frames 1–330 at 30 fps, and frame 330 matches frame 1. The lesson film is 30 seconds, 1920×1080. The spoken script is the `halophila_ovalis` transcript. Subtitles along the bottom use those same words. There is no music, no growth clip, and no pitch file.

Entry scripts in this folder: `_build_phone.py`, `_build_lesson.py`. Builders: `../halophila_ovalis_build/`.
