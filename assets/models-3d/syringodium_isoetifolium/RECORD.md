# Syringodium isoetifolium

These four files are the current ones.

| Role | File |
|------|------|
| Blender for the phone model | `syringodium_isoetifolium.blend` |
| Blender for the lesson | `syringodium_isoetifolium_lesson.blend` |
| Lesson video | `syringodium_isoetifolium_lesson.mp4` |
| Phone model | `syringodium_isoetifolium.glb` |

The app plays the copies in `app/assets/models-3d/`:

- `syringodium_isoetifolium.glb` — the plant you rotate
- `syringodium_isoetifolium_lesson.mp4` — the lesson, with the five spoken lines

The lesson video is 30 seconds at 1920×1080 (900 frames, 30 fps), rendered from `syringodium_isoetifolium_lesson.blend`. It has those five English lines and no music. The leaves in that film are round. The same file is in `app/assets/models-3d/`.

The lesson video is 30.000 seconds, 1920×1080, H.264 picture and AAC speech, 7,231,294 bytes. The five English lines are in the file, and there is no music. The app copy is the same file.

Builders live in `assets/models-3d/syringodium_isoetifolium_build/`. Entry scripts live in this folder. The short brief is `syringodium_isoetifolium.md`.
