An agent that builds this species reads this file and no other species plan.

Slug: `thalassia_hemprichii`. Prefix: `TH`. Common name: sickle seagrass.

Private builders: `assets/models-3d/thalassia_hemprichii_build/`. Blender: `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe` in the background. If Windows blocks a generated PowerShell script, run `blender.exe --background --python` directly.

## Not a straight strap

The leaf curves. The blade carries short black bars. The rhizome is thick, with scars between shoots. A straight green strap with no bars is the wrong plant.

Presentation: a side angle so the curve reads, then a close pass where the black bars are visible in the blade. Do not film it like the noodle or the ribbon tip lessons.

Roots: a thick rhizome. Scars sit between the shoots. Roots leave the nodes and stay in the sand. Do not add Enhalus bristles.

Seabed: the shared uneven bed only.
